========================================================================
   ATELIER YUMIA: THE ALCHEMIST OF MEMORIES & THE ENVISIONED LAND
   Traduzione Italiana Amatoriale al 100% (Dialoghi, UI e Scelte)
   Versione Gioco: v1.0.7 (Compatibile con Steam PC)
========================================================================

CONTENUTO DELLA CARTELLA:
- PACK00.pak             -> Il file di gioco contenente tutti i testi in italiano.
- Installa_Patch_ITA.bat -> Script per installazione automatica in 1 clic.
- Ripristina_Originale.bat -> Script per disinstallare la patch e ripristinare il gioco.

------------------------------------------------------------------------
COME INSTALLARE (METODO SEMPLICE - 1 CLIC):
------------------------------------------------------------------------
1. Assicurati che il gioco sia chiuso.
2. Fai doppio clic su "Installa_Patch_ITA.bat".
   (Lo script trovera' automaticamente la tua cartella di Steam e creera'
   un backup di sicurezza del tuo file originale).
3. Avvia il gioco su Steam.
4. Nelle impostazioni di gioco (Lingua del testo), seleziona "Español".
5. Buon divertimento in italiano!

------------------------------------------------------------------------
COME INSTALLARE MANUALMENTE (SENZA SCRIPT):
------------------------------------------------------------------------
1. Vai nella cartella di installazione del gioco su Steam:
   (solitamente: C:\Program Files (x86)\Steam\steamapps\common\Atelier Yumia\Data\)
2. Rinomina il file "PACK00.pak" in "PACK00.pak.original" (per sicurezza).
3. Copia il file "PACK00.pak" di questa cartella dentro la cartella "Data" del gioco.
4. Nel gioco imposta la lingua del testo su "Español".

------------------------------------------------------------------------
COME DISINSTALLARE:
------------------------------------------------------------------------
- Fai doppio clic su "Ripristina_Originale.bat"
  oppure
- Da Steam: Tasto destro sul gioco -> Proprieta' -> File installati -> Verifica integrita' dei file.
